360 DEGREE SONGS — STARTER SITE\n\nFREE HOSTING RECOMMENDATION: GITHUB PAGES\nThis is a responsive static website starter. It has a home page, mobile navigation, music discovery cards, search, genre filters, Afrobeats and Gospel sections, and artist submission link.\n\nDEPLOY USING ANDROID / FIREFOX\n1. Extract this ZIP on your phone.\n2. Sign in at https://github.com (create a free account if needed).\n3. Create a NEW PUBLIC repository named 360-degree-songs.\n4. In the repository choose Add file > Upload files.\n5. Upload index.html, styles.css and app.js from the extracted folder. Commit changes.\n6. Open repository Settings > Pages.\n7. Under Build and deployment select Deploy from a branch; choose main and /(root); Save.\n8. Wait for deployment. Your URL will be https://YOUR-USERNAME.github.io/360-degree-songs/\n\nBEFORE LAUNCH\n- In index.html replace REPLACE-WITH-YOUR-EMAIL@example.com with your real submissions email.\n- Replace demo discovery cards in app.js with verified releases.\n- Add your social links, privacy policy and contact information.\n\nMUSIC RIGHTS & API LIMITS\nThis site links to platform search results; it does not download or host copyrighted music.
